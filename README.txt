SPARKELO — сайт веб-студии

Файлы:
- index.html — готовый адаптивный сайт. CSS и JavaScript уже внутри.

Как посмотреть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Как опубликовать:
Загрузите index.html в репозиторий GitHub Pages или на любой статический хостинг.

Что можно изменить:
- Цены и описания услуг — найдите нужный текст в index.html.
- Ссылки портфолио — найдите адреса github.io.
- Telegram и Instagram — найдите sparkelo_web и sparkelo.2.

Примечание:
Анимации ноутбука, свечения, появления блоков и мобильное меню реализованы на CSS/JavaScript.
Google Fonts подключается онлайн; при отсутствии интернета используется системный шрифт.
